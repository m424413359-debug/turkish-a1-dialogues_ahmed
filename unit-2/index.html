جرّب: أين الشيء؟

اكتب اسماً (مكان أو شخص) وشوف اللاحقة الصحيحة.

Var = يوجد · Yok = لا يوجد

ترتيب الجملة بالتركي عكس العربي غالباً: المكان أولاً (مع ‎-DA)، ثم الشيء، ثم var/yok في الآخر.

المكان + DAالشيءvar / yok

للسؤال نضيف mı: var mı? (هل يوجد؟) — yok mu? (ألا يوجد؟)

«عندي» بالتركي = معي يوجد: Bende 20 lira var. = معي 20 ليرة.

بعد الرقم يبقى الاسم مفرداً: üç kitap ✓ وليس üç kitaplar ✗

النفي بكلمة değil + اللاحقة: işte değilim. والسؤال بـ mI + اللاحقة: hasta mısın?

(y) حرف وصل يظهر فقط إذا انتهت الكلمة بحرف علّة: hastayım، evdeyiz.

مولّد التصريف

اكتب صفة أو مهنة أو مكان + DA، وشوف الأشكال الأربعة لكل الضمائر.

كم؟ بكم؟ أي ترتيب؟

Kaç? = كم (عدد) — بعدها الاسم مفرد: Kaç öğrenci var?

Ne kadar? = بكم / كم (سعر أو كمية): Bu ne kadar?

Kaç lira? = بكم ليرة؟ — Kaç yaşındasın? = كم عمرك؟

Saat kaç? = كم الساعة؟ ← Saat iki. — Saat kaçta? = في أي ساعة؟ ← Saat dokuzda.

Kaçıncı? = أي رقم بالترتيب؟ ← birinci, ikinci, üçüncü…

أمثلة الكتاب

مفتاح كل اللواحق: التناغم الصوتي Ünlü uyumu

اللاحقة «تتلوّن» حسب آخر حرف علّة في الكلمة. في الكتاب يكتبونها بحروف كبيرة:

A = a أو e (نوعين) — مثل ‎-DA ‎-lAr

I = ı أو i أو u أو ü (أربعة أنواع) — مثل ‎-(y)Im ‎-sIn ‎mI

D = d أو t حسب الحرف الأخير (قاسٍ أم لا)
